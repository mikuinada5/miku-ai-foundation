## 8. 写真・イラスト・図形・図解・装飾

### 8.1 選定の順番

1. 視覚素材の**仕事**を明らかにする：証拠、具体性、比較、感情、構造理解、識別、雰囲気など。
2. その仕事に、写真・イラスト・図・抽象形状・文字だけのどれが適するか比較する。
3. 素材のリアリティ、距離感、視点、光、質感、構図を評価する。
4. 情報やブランドにない意味・価値観・因果・事実を素材で付加していないか確認する。
5. 画面全体の視覚言語と一致するか。意図的に混ぜるなら理由を持つ。
6. 権利、出典、人物表現、AI生成物の真正性・実物誤認の管理は該当Sourceへ送る。

### 8.2 素材別の向き・不向き

| 素材 | 有効な状況 | 注意する状況 |
|---|---|---|
| 写真 | 実物、商品、空間、情緒、質感を見せる | 実在性の誤認、構図の主従逆転、文字との干渉 |
| イラスト | 抽象概念、親しみ、様式の統一、実在人物を特定しない説明 | ステレオタイプ、内容の正確性、幼さの出過ぎ |
| 図解 | 関係、仕組み、プロセス、比較を理解させる | 因果・階層・比例の捏造 |
| グラフ・表 | 数量、比較、推移、一覧を読む | 数値の出典、目盛、単位、誤差、過剰装飾 |
| 抽象形状 | 世界観、区切り、リズム、視線 | 意味のない飾りが主役を奪う |
| タイポのみ | 言葉が持つ力、編集性、余韻 | 長文の判読、単調さ、弱い情報階層 |

### 8.3 「なんとなく埋める」を避ける

素材を削って目的を損なわなければ、削除候補。ただし、情緒や余韻、ブランド固有の体験を担う素材は「情報量が増えない」だけで不要と判定しない。**役割があるか**で判断する。

## 素材選択の比較例

**「利用者の安心感」を伝えたい場合**
- 実際の利用体験が根拠になるなら、許可された現場写真。
- 特定の実在人物の提示が不要なら、状況を抽象化したイラスト。
- 目で追うべき手順が主役なら、流れの図。
- 言葉の力が主役なら、画像を使わず文字と余白。

**見せると誤読される可能性:** 架空の人物を実利用者の声に見せる、図の線で未確認の因果を示す、実物写真のようなAI画像を証拠と誤認させる。こうした事実・権利判断は既存Sourceで確認し、Coreは創作しない。
