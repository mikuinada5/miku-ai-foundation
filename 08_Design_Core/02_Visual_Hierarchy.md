## 3. 情報階層と視線誘導

### 3.1 最初に「何を、どの順で」見てほしいか決める

- 最初の視点を1点に集める必要があるか、全体比較を最初に見せるべきかを決める。
- 主役をサイズだけに頼らず、位置、コントラスト、余白、形の違い、画像内の向き、重なりなどの組合せで作る。
- 情報優先度と視覚的強さが食い違っていないかを確認する。装飾だけが最も強く見えるなら、目的に沿う例外か検討する。
- CTAは必要な場合に明確化する。鑑賞・理解・記録が目的なら、購入・申込みの動線を捏造しない。

### 3.2 視覚階層の操作子

| 操作子 | 期待効果 | 注意 |
|---|---|---|
| サイズ差 | 重要度、入口 | 全部大きいと主役が消える |
| 重量差 | 見出し、キーワードの差 | 太字の多用は階層を潰す |
| 明度・色差 | 強調、グループ識別 | 意味を色だけで符号化しない |
| 位置 | 初期注目、視線の流れ | 文化・媒体・閲覧条件で変わる |
| 余白 | 分離、格付け、集中 | 関連情報の分断に注意 |
| 近接 | 同じ意味のまとまり | 違う関係を示す誤読に注意 |
| 枠・背景 | 区切り、比較、注記 | 枠だらけはノイズになりやすい |
| 向き・線・図形 | 関係、方向 | 因果や順序を捏造しない |
| 写真・顔・視線 | 感情、方向、文脈 | 主情報を奪うことがある |

### 3.3 まず構造、次に装飾

1. 装飾と色を一旦外しても情報のまとまりが理解できるか。
2. 白黒や低彩度でも主従・比較が成立するか。
3. 写真や装飾を追加したとき、必要情報の判読・視線が改善するか。
4. 一部を削ったとき情報理解が損なわれるか。損なわれない要素でも情緒的役割が明確なら保持可。

## 現場の検査順序

1. **三秒仮説:** 初見で何が最初に見えると想定したか。これは推測であり、検証した観察結果と区別する。
2. **目を細める確認:** 文字内容を読まず、明度・サイズ・面積・配置だけでも主従が意図どおりか。
3. **内容順の確認:** 最も大きい要素が主情報とは限らない。証拠や比較の同時認識が必要なら多点の入口も許容する。
4. **意味の検査:** 色・矢印・囲みにより未承認の優劣、時系列、因果を暗示していないか。
5. **閲覧文脈:** 遠方投影・小画面・短時間接触では必要な階層が変わる。具体的な閾値は媒体Sourceへ委ねる。

**典型的な修正:** 見出しをさらに大きくする前に、競合しているアクセント色・画像のコントラスト・群間余白を見直す。
