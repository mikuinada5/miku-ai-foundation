## 6. 色彩判断

### 6.1 色の役割を最初に指定する

1. **Identity:** ブランド・シリーズの識別。
2. **Hierarchy:** 重要情報の強調と背景化。
3. **Semantic:** 状態・種類・比較対象の区別（言語や形と併用）。
4. **Mood:** 温度、緊張、明るさ、時代感、素材感。
5. **Depth:** 前景・背景・空間の関係。

一色に複数の役割を持たせることは可能だが、役割が衝突していないか確認する。

### 6.2 配色を選ぶ具体手順

1. 承認済みブランドカラーや禁止色を確認。存在しない場合は自由裁量だが固定の汎用パレットは採用しない。
2. 主役と背景、文章と補助情報の**明度関係**を考える。色相の美しさだけで判読性を評価しない。
3. 色数を「必要な意味の区別」「主役の強さ」「世界観の一貫性」から決める。少色が常に正義ではない。
4. 色相関係（類似・対比など）、彩度差、面積比、質感、周囲の色による見え方を組合せて選ぶ。
5. 一部の色をモノクロにした場合に階層が消えないか、背景画像との重なりで判読が落ちないか確認する。
6. 媒体別のアクセシビリティ・印刷・ディスプレイ仕様へ接続する。Coreは媒体固有の数値要件を制定しない。

### 6.3 使い分けの判断

- **類似する色相:** 統一、連続、落ち着きに寄りやすいが、強調不足に注意。
- **反対・離れた色相:** 区別、活力、強調に使えるが、面積・彩度によって緊張が強すぎる場合がある。
- **無彩色を軸にアクセント:** 主役や写真を立てやすいが、無個性を防ぐ設計上の核が必要。
- **低彩度中心:** 穏やか・上質の仮説になりうるが、対象や目的によっては弱く見える。
- **高彩度中心:** 元気・現代的などの仮説になりうるが、全面使用で階層が壊れることがある。
- **ダーク基調:** 没入感、緊張、質感を演出できる一方、小文字や長文、発光表現の過剰に注意。

「青＝信頼」「緑＝自然」「黒金＝高級」は**文化・ブランド・文脈に依存する連想仮説**であり、自動決定ルールではない。

## 配色を実務で決めるための比較軸

| 比較する属性 | 問い | ありがちな誤り |
|---|---|---|
| 明度差 | 文字と背景、主役と周辺が区別できるか | 色相だけ変えて判読性が変わらない |
| 彩度差 | 注意を集めたい場所を限定できているか | 全要素が鮮やかで主役が消える |
| 面積比 | 強い色は必要な場所に使われているか | アクセント色が背景を支配する |
| 同時対比 | 隣接色の影響で意図せず濁る・強く見えるか | 単色見本だけで採否を決める |
| 光・媒体 | 投影、紙、暗い画面で色がどう変わるか | 編集画面のみで保証する |
| 意味 | 色が無根拠に善悪・優劣・状態を示さないか | 赤緑だけで区別させる |

### 色の具体指定に至るまで
1. 先に役割（背景・文章・主役・意味識別）を決める。
2. 明度構造を選び、採用する色相・彩度が目的の印象を支えるか比べる。
3. 写真・ロゴ・ブランド指定との関係で面積を調整する。
4. 実画面を見て確認する。特定の比率・数値を全媒体共通の規則と偽らない。

**補足:** 色覚・コントラストの法的または規格上の閾値は適用媒体の正式Sourceで確認する。
